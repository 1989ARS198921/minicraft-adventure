# MiniCraft Mobile V3 — Bedrock-style controls

Обновление сенсорного управления на основе V2.

## Управление
- Левый фиксированный джойстик — движение.
- Правая половина — отдельная зона обзора свайпом.
- 🏃 Бег — удерживать кнопку.
- 🧎 Присед — удерживать кнопку.
- 🦘 Автопрыжок — переключатель.
- ⬆️ Прыжок — удерживать; двойное нажатие включает/выключает полёт.
- ⛏️ Удержание кнопки — непрерывное разрушение блоков.
- 🧱 Установка блока — отдельная кнопка.
- Свайп по хотбару — быстрое переключение слотов; тап по слоту — прямой выбор.
- ⛏️/🧱 — режим действия по короткому тапу в зоне обзора.

Для телефона рекомендуется альбомная ориентация. Игра требует HTTPS/HTTP-сервера, а Three.js загружается из CDN.
