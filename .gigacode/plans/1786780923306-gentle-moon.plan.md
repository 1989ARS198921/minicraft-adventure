# План исправления критических ошибок и доработки MiniCraft RPG

## КРИТИЧЕСКИЕ ОШИБКИ (БЛОКИРУЮТ ЗАПУСК)

### ❌ Ошибка 1: `addBlock` уже объявлена в world.js
- **Файл:** `app/js/world.js`
- **Строка ~513:** `export function addBlock(x, y, z, type)` — ПРАВИЛЬНОЕ объявление
- **Строка ~590:** `import { addBlock } from './world.js';` — ОШИБКА: импорт из самого себя!
- **Причина:** Двойное объявление одной функции
- **Решение:** Удалить строку `import { addBlock } from './world.js';` (строка ~590). Функция уже экспортируется, её можно вызывать напрямую внутри модуля.

### ❌ Ошибка 2: `Cannot read properties of undefined (reading 'length')`
- **Файл:** `app/index.html`
- **Строка 1888:** `monsters.length` — crash!
- **Причина:** `spawnCastleMonsters()` (строка 1721) делает `return;` без значения при `!scene`, а не `return [];`
- **Решение:** Изменить строку 1723 с `if (!scene) return;` на `if (!scene) return [];`
- **Аналогично:** `spawnCastleBosses()` (строка 1801) — тоже изменить на `return [];`

### ⚠️ Проблема 3: Дублирующийся import в player.js
- **Файл:** `app/js/player.js`
- **Строки 10-11:** `checkCityCollisions` и `getCityBlockAt` импортируются ДВАЖДЫ из `cities.js`
- **Решение:** Удалить дублирующуюся строку импорта
