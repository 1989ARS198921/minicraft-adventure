# MiniCraft Adventure RPG V3

Первый игровой прототип Пещеры гоблинов.

## Цепочка
Вход → лагерь → гоблин → ключ → склад → сундук → мешок яблок → секретный проход → зал вожака → босс.

## Следующий шаг
Связать эти события с реальными 3D-координатами мира:
- построить физическую пещеру из блоков;
- разместить факелы и сундуки;
- добавить настоящих гоблинов в мир;
- сделать здоровье/урон;
- сделать реальную дверь и ключ;
- привязать завершение квеста Бориса к возвращению в деревню.
