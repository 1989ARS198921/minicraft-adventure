# MiniCraft Adventure RPG V50 — 3D Vertical Slice

This build adds a playable 3D vertical slice to the existing systems:

**Village → forest/road → cave → chest → goblins → cave boss → return to Boris → reward**

Desktop: WASD, mouse, Space, E, F, Shift.
Mobile: left joystick, right-side touch look, attack/jump/action buttons and hotbar.

The build is browser-based and uses Three.js from a CDN.
