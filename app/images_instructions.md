# Инструкция по созданию изображений для RuStore

## Файлы, которые нужно создать:

### 1. Иконка приложения
- **Файл:** `icon_512.svg` → `icon_512.png`
- **Размер:** 512×512 px
- **Формат:** PNG, 32-bit, без прозрачности
- **Содержание:** Пиксельный блок земли, надпись "MiniCraft Adventure", небо и облака

### 2. Обложка (Feature Graphic)
- **Файл:** `feature_graphic.svg` → `feature_graphic.png`
- **Размер:** 1024×500 px
- **Формат:** PNG или JPG
- **Содержание:** Игровой мир с персонажем, монстром, деревьями, блоками

---

## Как конвертировать SVG → PNG

### Способ 1: Онлайн-конвертер (проще всего)
1. Откройте https://cloudconvert.com/svg-to-png
2. Загрузите `icon_512.svg` → Скачайте `icon_512.png` (512×512)
3. Загрузите `feature_graphic.svg` → Скачайте `feature_graphic.png` (1024×500)

### Способ 2: Браузер
```powershell
# Откройте SVG в браузере
start icon_512.svg
start feature_graphic.svg

# Сделайте скриншот или используйте инструменты разработчика (F12)
# Для SVG можно экспортировать через правую кнопку мыши
```

### Способ 3: Node.js (если установлен sharp)
```powershell
npm install -g sharp-cli
svg2png icon_512.svg -w 512 -h 512
svg2png feature_graphic.svg -w 1024 -h 500
```

### Способ 4: Inkscape (бесплатная программа)
1. Установите Inkscape: https://inkscape.org/
2. Откройте SVG файл
3. File → Export as PNG
4. Установите размер 512×512 (для иконки) или 1024×500 (для обложки)

---

## Требования к изображениям для RuStore

| Элемент | Размер | Формат |
|---------|--------|--------|
| Иконка | 512×512 | PNG |
| Feature Graphic | 1024×500 | PNG/JPG |
| Скриншоты (минимум 2) | Любой, но не менее 720p | PNG/JPG |

## Альтернатива: сгенерировать в ChatGPT

Вы можете скопировать описания из SVG и попросить ChatGPT (DALL-E 3) создать изображения:

**Для иконки:**
> Создай иконку приложения для мобильной игры в стиле Minecraft. Квадрат 512x512. На переднем плане — пиксельный блок земли с зелёной травой сверху. Фон — голубое небо с облаками. Внизу текст "MiniCraft Adventure" жёлтыми буквами. Стиль — пиксель-арт.

**Для обложки:**
> Создай баннер 1024x500 для мобильной игры. Слева — пиксельный персонаж в синей рубашке с мечом. Справа — далёкий скелет-монстр. По бокам — пиксельные деревья и стопки блоков. В центре надпись "MiniCraft Adventure". Стиль — пиксель-арт, яркий, солнечный день.
