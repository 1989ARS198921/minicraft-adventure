# MiniCraft Mobile V2

Мобильная сборка 3D MiniCraft.

## Управление
- Левая сторона: плавающий виртуальный джойстик — движение.
- Правая часть экрана: свайп — обзор камеры.
- ⬆️ — прыжок; двойное нажатие — полёт.
- ⛏️ — ломать блок.
- 🧱 — ставить блок.
- ⛏️/🧱 — выбрать действие для быстрого тапа по миру.
- 🎥 — переключение камеры.
- 🎒 — рюкзак.
- 🔥 — костёр.
- При удержании области обзора около 0.5 с действие повторяется один раз.

Рекомендуется горизонтальная ориентация телефона.
