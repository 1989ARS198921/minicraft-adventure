# V50 — Playable Systems Milestone

The project has been advanced to the V50 target.

## Added
- Expanded player RPG stats: HP, mana, attack, defense, XP, levels, gold.
- Inventory with weapons, food, potions and a fire spell.
- Hotbar selection and item use.
- Quest chain with four stages.
- Regions/discovery.
- Day/time/weather state.
- Enemy spawning and combat resolution.
- Boss state.
- Chest/loot interaction.
- Mobile action controls for attack, jump, sprint and mining/interact.
- Save/load using localStorage.
- Child-friendly readable HUD.

## Vertical slice target
Village → forest → cave → enemy → chest → quest return → reward.

## Honest status
This is a systems milestone. A full finished 3D game still needs authored 3D levels/assets, animation, real collision/physics, navigation AI, audio, and extensive Android device testing.
