# MiniCraft Adventure RPG — V11–V30 integrated roadmap

This package jumps the project to the **V30 milestone**. It contains a unified systems layer intended to replace the fragmented prototype versions while keeping the existing HTML/app structure.

## Implemented in the V30 systems layer
- Unified persistent game state
- Player HP / defense / attack
- XP and level progression
- Gold
- Inventory and hotbar selection
- Food/potion healing
- Quest state machine
- World region discovery
- Enemy battle resolution
- Save/load with localStorage
- Automatic persistence after state changes
- Mobile-friendly HUD and controls
- Resettable save state

## V11–V15: Core
World, player, collision, mobile input, NPC interaction, dungeon transitions.

## V16–V20: RPG
Weapons, magic, enemy AI, XP, levels, loot, inventory, equipment.

## V21–V25: Adventure
Village, NPC dialogue, shops, quest chains, dungeon rooms, keys, doors, puzzles.

## V26–V30: World
Multiple regions, weather/time, bosses, secrets, fast travel, expanded save data, optimization.

## Important
V30 is a **working systems milestone**, not a finished commercial-size game. The remaining work is primarily connecting these systems to a polished 3D world, assets, animation, collision, audio and content.
