# MiniCraft Adventure RPG — Final Game Design

## Core fantasy
A child-friendly first-person 3D adventure: explore a voxel-like world, visit a village, accept quests, enter dungeons, fight simple monsters, find treasures and grow stronger.

## No companions
The player is intentionally solo. NPCs provide quests, shops and story, but do not follow the player.

## World
- Village hub
- Forest
- Mountains
- Swamps
- Ruins
- Multiple dungeon levels
- Secret rooms and treasure

## Core loop
Explore → discover → quest → dungeon → combat → loot → return → reward → level up → unlock new region.

## Mobile
Left joystick for movement, right-side look zone, attack, jump, sprint/crouch, hotbar swipe, hold-to-mine/interact.

## RPG
HP, attack, defense, XP, levels, weapons, consumables, loot, gold and simple magic.

## Child-friendly
Clear goals, readable UI, low-fright enemies, no required companion management, safe village hub.
